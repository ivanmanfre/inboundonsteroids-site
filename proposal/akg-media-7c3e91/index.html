How one audit gets made

The same approach I run for client audits today, rebuilt for creator marketing and set up on your accounts.

  1. Add the brand

    One row in a Google Sheet: brand name and website. Add competitors if you know them; leave the cell empty and the system picks three from the brand's category and site.

  2. Find the campaigns

    YouTube through Google's official YouTube Data API: brand-name searches, then each video's views, date, channel size and the paid-promotion flag the uploader sets. Instagram and TikTok through Apify: posts that tag or mention the brand, its hashtags, and paid-partnership labels where the platform shows them. The brand's own uploads and posts about a different company with the same name get removed.

  3. Read every post

    Claude reads each caption and description and sorts the post: paid and disclosed, likely paid (promo code, affiliate or tracking link), or an organic mention. It decides from the post itself, so a new brand needs no setup.

  4. Compare and write

    The same pass runs for each competitor. One analysis step then writes the comparison and the gaps, and every number on the page links back to the post it came from.

  5. Check and publish

    A last check rejects any claim without a source behind it. When data is missing, the page says "not found". The page goes live on your subdomain, hidden from Google, the link is written back to the sheet, and your team gets a Slack message.

For the first two weeks it runs, I read every audit before it reaches a brand and tune whatever is off. After that it runs on its own.
