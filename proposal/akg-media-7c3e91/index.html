How one audit gets made

The approach I run for client audits today, set up on your accounts.

  1. Add the brand

    A row in a Google Sheet: name and website, competitors optional.

  2. Find the campaigns

    YouTube via Google's official API, with views, channel size and the paid flag. Instagram and TikTok via Apify: tags, mentions, hashtags, paid-partnership labels.

  3. Read every post

    Claude sorts each one: paid and disclosed, likely paid (promo code or tracking link), or organic.

  4. Compare and write

    Same pass for each competitor, then the comparison and the gaps. Every number links to its post.

  5. Check and publish

    Claims without a source get rejected. Page goes live on your subdomain, link back in the sheet, Slack ping.

For the first two weeks I read every audit before it reaches a brand. After that it runs on its own.
