Turn call notes
into an outbound brief.

A small Claude skill that keeps the buyer evidence next to the message you're about to write.

Give it the offer, a target segment and call notes you're allowed to use. It prepares a campaign brief, a resource idea and two draft messages. Missing information stays visible.

Starter for OutboundHub. Paolo has not reviewed or approved it. It writes drafts; it has no sending or CRM integration.

Fictional worked example Illustrates the expected format

Supplied note

“We have a sales team. We want to test the new module with Italian manufacturers before we hire another SDR.”

Buyer hypothesisSales leader at an Italian software scaleup. Role and company fit still need confirming.
Problem from the noteTest demand for a new module before adding headcount.
Useful resourceA pilot-readiness brief that defines the segment, decision rule and sales handoff.
MissingDecision owner, test timing, qualification criteria and budget.

The kind of opener it helps prepare

“You mentioned testing the new module before hiring another SDR. I've put together a brief for agreeing what that pilot needs to prove. Want me to send it over?”

This opener uses a fictional prior conversation. It would only be suitable if the recipient actually said that. This example was written for OutboundHub; it is not a live Claude run.

How to try it

Open the instructions, give them to Claude with your source notes and ask for a campaign brief. Keep the source labels when reviewing the output.

Where Paolo adds value

Your actual campaign experience, qualification criteria and Italian phrasing make this useful for your audience. I'd develop the final version from that material.
