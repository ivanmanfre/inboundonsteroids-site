01 / Paid ads

Match the banner to the advertised offer

On the GOLDBOGO ad landing page, the product cards show the BOGO code while the top banner promotes a separate buy-two-get-one deal. One homepage reviewer reports expecting a BOGO free item and receiving one balm; a page-specific banner could make the advertised offer clearer.

One change

On the BOGO sale page only, compare the existing Autumn bundle banner with: "Gold & Black BOGO. Use GOLDBOGO at checkout." Keep the current BOGO hero, redemption instructions, prices and discounts unchanged.

02 / Paid ads

Test sale page versus Roll-Up page for knee-pain ads

Two knee-pain video ads with near-identical copy send clicks to two pages already in use: the BOGO flash-sale page and the Extra Strength Roll-Up page. Because each ad opens with a different question, their results cannot show which page sells better until the copy is held the same.

One change

Run the stairs video ad in a Meta A/B test with the copy unchanged, splitting the audience between two copies, one linking to the BOGO sale page and one to the Extra Strength Roll-Up page while the BOGO is live. The sale page shows the GOLDBOGO code and the Roll-Up page does not, so the page and how visible the offer is change together.

03 / Your store

Clarify the THC level of the Maximum formula

A one-star homepage review describes expecting THC in a purchase. Your composition guide already lists the Maximum Full Spectrum formula at under 0.3% THC; the test is whether stating that limit before purchase sets clearer expectations.

One change

On the Gold box set page, test: "Check the formula you are buying. Our Maximum Full Spectrum formula contains under 0.3% THC. See the full formula here." Link to the existing composition table, keep the strength quiz, and run separately from the travel-size test.

Test a travel-size starter beside the box set

The Gold box set page sells a four-product set, and a reviewer on that page advises trying a travel sized balm first if you are sensitive to smell. The page also has a 60-second strength quiz lower down.

One change

On the Gold and Black box set pages, one version adds a starter option next to the strength quiz link and the other does not: "Not sure about scent or strength? Start with the 0.5oz travel roll-up." Link it to the travel roll-up in that set's strength.
