02 / Your store

Show the size-up note beside the Sol Azul size picker

Sol Azul's product details say it runs small and to size up, and the FAQ says customers pay return shipping. A wrong size therefore has a cost, so the note may be worth seeing before a size is chosen.

One change

On the Sol Azul page, add a one-line note directly under the size picker: "Runs small, so we suggest sizing up." Add the model's Sol Azul size only if you've confirmed it. Show it to half of Sol Azul visitors. The other half sees the current page.

Full test plan & sources +

What we saw
Sol Azul's product details say it runs small and to size up, and the FAQ says customers pay return shipping. A wrong size therefore has a cost, so the note may be worth seeing before a size is chosen.

What to measure
Sol Azul purchases per page visitor, both versions, same 3 to 4 weeks. Tag orders by version, and compare size-related return or exchange requests per order 14 days after delivery.

03 / Your store

Offer a £5 pin add-on beside Sol Pintores

A Sunball Enamel Pin bought alone costs £5 plus £5 UK shipping, while Sol Pintores at £75 ships free over £60. Your FAQ says orders can't be combined, so the pin only ships free if added before paying, and the Sol Pintores page shows no add-on.

One change

On the Sol Pintores page, add an optional tick box under the size picker: "Add the Sunball Enamel Pin for £5". Show it to half of visitors. The other half sees the current page. Keep jersey price and shipping rules unchanged.

Full test plan & sources +

What we saw

What to measure
