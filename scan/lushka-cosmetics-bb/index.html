02 / Paid ads

Let set buyers add the £35 serum

Your £60 set excludes the serum, which your homepage calls “The heart of the Lushka system”. The serum costs £35 separately; your monthly five-step subscription already includes it.

From your public ad

“targeted scalp care and hair growth support”
View the actual ad ↗
One changeAdd an optional, unticked serum choice below the full set’s quantity selector, adding both to the same cart. Compare with the current page.
Sources & how to check the result +

What to measure
Compare revenue per visitor from the first order. Check that adding the serum choice does not reduce set purchases or completed checkouts.

03 / Your store

Make the £10 trial easier to find

Your four-step set costs £60, while the £10 Travel Kit lets people try the same routine before choosing full sizes. The set page already links to it lower down.

One changeBeside the full set’s Add to Cart button, add a link: “Try the four-step Travel Kit before choosing full sizes.” Compare with the current page.
Sources & how to check the result +

What to measure
Compare revenue per visitor, counting both set and travel kit orders. Check whether the trial replaces too many full set purchases.
