Creator numbers get compared to paid-channel numbers in the same weekly report. We ask for that comparison and clients are right to want it. It only works if both numbers were produced under the same rules. Often they are not. Click-through attribution credits a channel when a user clicks and then converts inside a window. View-through credits a channel when a user watches an ad and converts later without clicking at all. Some platforms and formats effectively have no view-through, so everything they report is click-through only. Put a click-through-only line beside a view-through-enabled line and the second one carries an advantage that has nothing to do with the campaign. The difference you are reading contains a measurement gap of unknown size. A concrete version of the same problem, from a public r/PPC thread this year: a TikTok Spark Ads campaign reported 121 clicks against 5 App Store downloads. "Clicks (all)" counts taps on the caption, the profile and the comments, so it was never 121 people heading to the store. And on iOS in 2026 the honest position is that attribution is triangulated from several partial signals. Any single platform number is a partial account of what happened. So the discipline is to name the model. State which attribution model each row is measured on, on the report itself, and agree the comparison rules before the campaign starts, while nobody is defending a result.
