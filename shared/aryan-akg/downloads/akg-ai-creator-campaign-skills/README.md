# 4 Claude skills for AI creator campaigns

A practical planning kit for marketing teams at AI and tech companies. The four skills help you assess a creator, write a brief, plan a first-month test and read the result. They use the facts you supply; no paid API is required.

## Use in Claude Code

Unzip this kit. Copy each `akg-*` folder into your project’s `.claude/skills/` directory, so each path ends in `.claude/skills/<skill-name>/SKILL.md`. Then start Claude Code in that project and invoke `/akg-creator-fit`, `/akg-creator-brief`, `/akg-first-month-test` or `/akg-campaign-readout`. Claude Code may also load a relevant skill automatically. See [Claude Code’s skill documentation](https://code.claude.com/docs/en/skills) for current installation details.

No installer or terminal script is included in the ZIP. Copying a folder is the whole setup. For a one-off use, open any `SKILL.md` and paste its text into a Claude chat with your campaign facts; the text acts as instructions in that conversation, not as an installed automatic skill.

## A sensible order

1. **Creator fit:** Supply product, target user, country, candidate links and any analytics or quoted fees.
2. **Creator brief:** Supply an approved product fact sheet, objective, candidate, deliverables and CTA.
3. **First month test:** Supply start date, spend ceiling, candidate list, tracking setup and success metric.
4. **Campaign readout:** Supply placement rows, costs, platform analytics and attributed outcomes.

Missing geography, sponsor cost or conversion data remains marked **Unknown** or **To confirm**. The skills do not make bookings, contact creators, access private data or invent campaign results.

Prepared as a working AKG Media resource preview. Your team should adapt the decisions and wording to its own campaign process before distribution.
