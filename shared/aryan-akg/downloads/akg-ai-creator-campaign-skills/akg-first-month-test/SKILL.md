# First month creator test plan

Use this when a team wants to learn which creator and message combinations deserve more investment. This is a planning tool, not a forecast or a promise that a single month will establish lift.

## Request inputs

Ask for product and target user, target countries, objective, campaign start date, available budget or spend ceiling, creator shortlist and quoted fees, production or review lead times, current conversion baseline, attribution setup, and any channel activity that could overlap. Ask which metric is the primary decision metric: qualified sign-ups, trials, purchases, or an awareness measure. If the user has no budget or baseline, plan the structure and show the missing decision inputs; do not invent a spend level or numerical target.

## Design a useful test

1. Write one main hypothesis in the form: "For [audience], [creator type or angle] will produce [observable outcome] because [reason]." Keep secondary questions small enough to interpret.
2. Define test cells by creator type and message or demo angle. For a creator-profile comparison, hold platform, use case, offer and core message consistent where possible; vary the creator profile deliberately. If multiple dimensions vary, name the confounders and limit conclusions to directional observations rather than a clean comparison.
3. Use the actual proposed dates, fees and deliverables to map a 30-day sequence: setup and tracking, brief and production, staggered launch, then reporting. If production cannot fit the month, say so and adjust the learning window rather than pretending it can.
4. Specify tracking before launch: unique links or codes, landing page, analytics owner, reporting snapshot dates and attribution window. Record the baseline and concurrent campaigns where available.
5. Set a decision rule for each cell before results arrive. Rules may use thresholds supplied by the buyer or relative evidence; do not manufacture "good" CPA or sample-size cutoffs. Mark a result inconclusive when the data is too thin, incomplete or confounded.

## Return

- A one-screen test plan with objective, primary metric, hypothesis, cells, measurement method and decision rule.
- A week-by-week table with owner, dependency and deliverable.
- A tracking table with creator, platform, angle, fee, link/code, launch date, spend, views, clicks, conversions and data source. Leave unknown values blank or **To confirm**.
- Three possible decisions at readout: expand, revise and retest, or pause, each tied to observed evidence.

Do not convert views into sales or present correlation as causal lift. If the buyer wants incrementality, propose a separately designed holdout or controlled test and state that this plan alone cannot prove it.
